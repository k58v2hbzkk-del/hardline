Hardline
Overview

Rules hardwired into chips nobody can change.

Write a rule. Hardline compiles it into a real logic chip, proves it's correct for every possible case, and mints it on X Layer through TapeOut. Any contract, vault or AI agent can then ask the chip "is this allowed?", and that answer can never be quietly edited.
